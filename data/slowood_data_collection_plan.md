# Slowood Data Collection Plan

Current baseline workbook: `assets/slowood_social_research_pack.xlsx`

Current sample snapshot:
- Slowood owned social rows: 17
- Competitor post rows: 22
- Xiaohongshu/search signal rows: 15
- Qualitative public signal rows: 21

Expansion targets:
- Slowood owned social audit: latest 30-50 public Instagram posts if accessible.
- Competitor benchmark: 4-5 related brands, 10-20 public posts per brand if accessible.
- Xiaohongshu/search intent: 80-150 public notes or search-result signals if accessible.
- Public comments/reviews: 30-100 public review or comment samples if accessible.

Collection rules:
- Respect public access limitations.
- Do not use private data.
- Do not fabricate missing values.
- If scraping is blocked, use the manual templates in this folder.
- Mark missing fields as blank or `not visible`.
- Treat all charts as sample-based directional insight until the dataset is expanded.

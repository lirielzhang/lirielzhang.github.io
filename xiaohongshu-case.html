Main Project · Content / Social Media

Xiaohongshu / RED Content Performance Analysis

A social media analytics project exploring how headline patterns and engagement signals can support content optimisation.

The project focuses on how lifestyle content can become more clickable, save-worthy and platform-native by analysing headline structure, user engagement and content hooks.

View Process View Content Testing Ideas

1. Project Context

Platform Context

Why Xiaohongshu / RED?

Xiaohongshu / RED is a lifestyle-focused UGC platform where users often discover places, products and experiences through search, recommendation feeds and personal notes.

In this context, the headline is not just a title. It works as the first content hook that affects whether users click, read, like or save a post.

Project Goal

What I wanted to find out

The goal was to identify patterns in higher-performing posts and use those insights to support content optimisation and AI-assisted headline generation.

  • What types of headline hooks appear more often in high-engagement posts?
  • Which signals suggest stronger user interest?
  • How can those patterns inform headline variants and A/B testing?

Observed Content Patterns

Pattern Why it may work Example direction
Location-specific hook Makes the post feel searchable and immediately relevant. “Hong Kong weekend idea…”
Benefit-led headline Tells users what they can get from reading or saving the post. “A place to learn AI without feeling overwhelmed…”
First-person experience Creates a more authentic and UGC-native tone. “I tried a coffee-and-learn space in Hong Kong…”
Curiosity angle Encourages clicks, but should not become exaggerated clickbait. “Not just a café…”

4. Content Application

Content Idea

Hong Kong café suitable for studying and casual AI learning

Based on the headline pattern analysis, the same content idea can be rewritten from different angles to test which hook better matches user intent.

Headline Variants
  • Not just a café: a Coffee-and-Learn space for curious beginners
  • A Hong Kong café where coffee meets beginner-friendly AI learning
  • Weekend idea in Hong Kong: take a coffee break and try an AI-Q test
  • A quieter way to start learning AI after work

A/B Testing Plan

The next step would be to test different headline angles and compare CTR, likes, saves and comments. The goal is not only to find the most attractive headline, but to understand which message angle best matches user intent.

Version Angle Main metric What it tests
A Location + weekend idea CTR Whether local discovery language increases clicks
B Learning benefit Saves Whether users find the content useful enough to save
C Curiosity Clicks + comments Whether the hook creates discussion without overpromising

Supporting Case

Xiaohongshu Content Performance & Headline Generation Prototype

A content analytics project exploring how Xiaohongshu post data can support headline optimisation.

This project includes public data collection, data cleaning, engagement-based headline review and an AI-assisted headline generation prototype.

RED data collectionData cleaningEngagement analysisHeadline pattern reviewPrompt designPrototype testing

Project role

Data collection and cleaning, sample selection, headline pattern review and prototype support.

Marketing problem

On Xiaohongshu, headlines affect whether users click, save and interact. The project asks what headline patterns can support stronger content planning.

Output

A simple AI-assisted headline generation prototype logic, with A/B testing proposed as a future improvement.

Workflow

Data-to-content workflow

Collect public RED posts Clean text and fields Rank by engagement Select useful samples Construct prompt logic Review generated outputs

Data collection

Collected public post data with Python, Selenium, Pandas and Requests.

Data cleaning

Removed duplicate records, emojis, garbled text and unnecessary fields.

Engagement review

Reviewed likes, favourites and headline features as engagement signals.

Analysis

Headline pattern matrix

Benefit

Shows what users can eat, buy, visit, save, avoid or learn.

Specificity

Uses location, scenario, price range or identity labels to make relevance clear.

Curiosity

Creates a reason to open the post without misleading the reader.

Content fit

Matches the headline promise with the actual post content.

SignalWhat it suggestsContent rule
High likes and favouritesUsers responded to the topic or hookKeep the promise clear and useful
Specific place or productContent is easier to judge and saveInclude location or use case when relevant
Long enough post contentMore context for prompt constructionUse examples with enough substance

Marketing takeaways

Headline review can become a practical content brief: benefit, specificity and content fit.

A/B testing plan

Future testing could compare headline angles, length and emotional hooks against click or save behaviour.

Limitations

Public engagement signals cannot prove full performance. The prototype logic is shown for portfolio explanation, not as a live product.

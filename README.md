# Wenli Zhang Digital Marketing Portfolio

A GitHub Pages static portfolio for junior Digital Marketing / Social Content / Marketing Assistant roles in Hong Kong.

## Files

- `index.html` — main portfolio content
- `style.css` — layout and visual design
- `script.js` — small interaction / reveal script
- `assets/Wenli_Zhang_CV.pdf` — CV download file, if included
- `assets/slowood_social_research_pack.xlsx` — research pack backup, not required for public display

## Recommended GitHub Pages setup

1. Create or open your GitHub Pages repository.
2. Upload all files in this folder to the repository root.
3. In GitHub, go to Settings → Pages.
4. Set Source to `Deploy from a branch`, Branch `main`, Folder `/root`.
5. Wait for GitHub Pages to publish.

## Positioning

The portfolio focuses on Social Content / Digital Marketing Assistant roles. The Slowood case is the hero case; the Xiaohongshu headline project is the supporting academic case.

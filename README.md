# Wenli Zhang Portfolio Final

This folder is the final GitHub Pages upload package.

## Files to upload

Upload everything in this folder to the root of your GitHub Pages repository:

- `index.html`
- `slowood.html`
- `xiaohongshu.html`
- `style.css`
- `script.js`
- `assets/`

## GitHub Pages setup

1. Open your GitHub Pages repository on GitHub.
2. Click `Add file` -> `Upload files`.
3. Drag all files and the `assets` folder from this folder into GitHub.
4. Commit to the `main` branch.
5. Go to `Settings` -> `Pages`.
6. Set source to `Deploy from a branch`, branch `main`, folder `/root`.
7. Wait 1-3 minutes, then open `https://lirielzhang.github.io/`.

If your repository uses a project path instead of the root user site, the live URL may be `https://lirielzhang.github.io/<repo-name>/`.
